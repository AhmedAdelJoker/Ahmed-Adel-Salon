# دليل تشغيل مشروع صالون برو (Salon Management Pro ERP)

هذا الدليل يشرح كيفية تنصيب، إعداد، وتشغيل المنظومة بالكامل.

## 1. متطلبات التشغيل (Prerequisites)

- **Node.js:** الإصدار 18 أو أحدث.
- **Python:** الإصدار 3.10 أو أحدث.
- **Package Managers:** `npm` للفرونت، و `pip` للباك إند.
- **Database:** SQLite (افتراضي) أو PostgreSQL (اختياري).

---

## 2. إعداد النظام الخلفي (Backend Setup)

1.  انتقل لمجلد الباك إند:
    ```bash
    cd backend
    ```
2.  أنشئ بيئة افتراضية وفعّلها:
    ```bash
    python -m venv .venv
    # Windows:
    .\.venv\Scripts\activate
    # Linux/Mac:
    source .venv/bin/activate
    ```
3.  نصّب المكتبات المطلوبة:
    ```bash
    pip install -r requirements.txt
    ```
4.  إعداد ملف البيئة `.env`:
    - انسخ `.env.example` إلى `.env`.
    - اضبط `SECRET_KEY` و `DATABASE_URL`.
5.  تشغيل المهاجرين (Migrations):
    ```bash
    alembic upgrade head
    ```
6.  إنشاء مستخدم مدير (Admin):
    - يمكنك استخدام سكربت البذر (Seeding) أو إنشاء أول مستخدم عبر الـ API.
7.  تشغيل الخادم:
    `bash
.\.venv\Scripts\activate
cd backend
python -m uvicorn app.main:app --reload
    `
    agy init

---

## 3. إعداد الواجهة الأمامية (Frontend Setup)

1.  انتقل لمجلد الفرونت:

        ```bash

cd frontend
cd public-site

        ```

2.  نصّب المكتبات:
    ```bash
    npm install
    npm run lint -- --fix
    npm run lint
    npx tsc --noEmit
    ```
3.  إعداد ملف البيئة `.env`:
    - تأكد من أن `VITE_API_URL` يشير إلى خادم الباك إند (مثلاً `http://localhost:8000/api/v1`).
4.  التشغيل في وضع التطوير:
    `bash
npm run dev
    `
5.  بناء نسخة الإنتاج (Production Build):
    ```bash
    npm run build
    ```

## 4. العمليات الإدارية الهامة

### أ. استيراد وتصدير البيانات

- **الاستيراد:** توجه لصفحة العملاء أو المخزون، استخدم زر "استيراد" وارفع ملف Excel مطابق للقالب المطلوب.
- **التصدير:** متاح في كافة الصفحات المالية والإحصائية بصيغ Excel/CSV.

### ب. النسخ الاحتياطي (Backup)

- قاعدة البيانات SQLite عبارة عن ملف `salon_pro.db`. يكفي أخذ نسخة منه دورياً.
- يفضل عمل Backup قبل تشغيل أي `alembic upgrade`.

### ج. حل المشكلات (Troubleshooting)

- **خطأ 401:** تأكد من أن التوكن لم ينتهِ، أعد تسجيل الدخول.
- **خطأ 404 في الـ PDF:** تأكد من وجود مجلد `generated_invoices` وصلاحيات الكتابة فيه.
- **التقارير فارغة:** تأكد من فتح وردية عمل (`Shift`) وتسجيل عمليات بيع فعلية.

---

## 5. ملاحظات النشر (Deployment)

- استخدم `Nginx` كخادم عكسي (Reverse Proxy).
- استخدم `Gunicorn` مع `Uvicorn workers` لتشغيل الباك إند في الإنتاج.
- تأكد من ضبط `FRONTEND_URL` في إعدادات الـ CORS في الباك إند.
